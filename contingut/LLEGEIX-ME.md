# Textos del web

Aquí hi ha **tots els textos** del web. Cada idioma té la seva carpeta (`ca` i `es`) amb els mateixos fitxers.

| Fitxer | Pàgina |
|---|---|
| `inici.md` | Pàgina d'inici |
| `suport.md` | Convida a un cafè |
| `qui-som.md` | Qui som |
| `privadesa.md` | Privadesa del web |
| `apps/<app>.md` | Fitxa de cada app (`verbs.md`, `paisos.md`) |
| `textos.yml` | Textos curts: menú, botons, peu de pàgina, etiquetes |

## Com s'editen

- La part de dalt, entre les dues ratlles `---`, té camps amb nom (`titol:`, `resum:`…). Canvia només el text que hi ha
  després dels dos punts. Si el text conté dos punts (`:`), posa'l entre cometes: `titol: "Hola: adeu"`.
- La resta del fitxer és text normal en Markdown: `**negreta**`, `*cursiva*`, llistes amb `- `, títols amb `## `
  i enllaços amb `[text](https://adreça)`.
- Si canvies un text en català, recorda canviar també el castellà.

## Com es publica

- **Des de github.com**: obre el fitxer al repositori, prem el llapis ✏️, edita'l i prem *Commit changes*.
  En un minut el web s'actualitza sol.
- **Des de l'ordinador**: edita el fitxer i demana a Claude que el publiqui.

Si hi ha algun error (per exemple, falta un camp), el web no s'actualitza i GitHub avisa per correu de quin fitxer és.
